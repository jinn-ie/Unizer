# Unizer 프론트엔드

React · TypeScript · Vite로 만든 모바일 웹 화면이에요.
실행 방법, 폴더 구조, 기능 지도는 [루트 README](../README.md)에 있어요.

## 자주 쓰는 명령 (`frontend` 폴더에서)

```bat
rem 개발 서버 (http://localhost:5173, /api 요청은 8000번 백엔드로 넘김)
npm run dev

rem 타입 검사 + 배포용 빌드 (dist 폴더)
npm run build

rem 코드 검사 (oxlint)
npm run lint
```
